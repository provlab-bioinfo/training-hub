# 🧬 ProvLab Bioinformatics Training Hub

Welcome to the **ProvLab Bioinformatics Training Hub**! This repository is the central resource for **hands-on bioinformatics and HPC training** at **ProvLab**.

The goal of this hub is to help teammates build **practical, real-world bioinformatics skills** through clear examples, guided exercises, and commonly used pipelines.

All materials are:
- Modular and self-paced
- Suitable for beginners through intermediate users

---


## 🧠 Audience

This training hub is intended for:

- **New ProvLab staff**
- **Researchers** new to HPC environments
- **Bioinformatics beginners** seeking hands-on pipeline experience

No prior HPC or bioinformatics experience is required. Content progresses from **beginner** to **intermediate**.
