# 🧬 ProvLab Bioinformatics Training Hub

Welcome to the **ProvLab Bioinformatics Training Hub**!  
This repository is the central resource for **hands-on bioinformatics and HPC training** at **ProvLab**.

The goal of this hub is to help teammates build **practical, real-world computational biology skills** through clear examples, guided exercises, and commonly used pipelines.

All materials are:
- Modular and self-paced
- Designed for real ProvLab workflows
- Suitable for beginners through intermediate users

---

## 📚 Table of Contents

### 🖥️ Linux Basics
Learn essential Linux commands for working on servers and HPC systems.

- Directory navigation (`cd`, `pwd`, `ls`)
- File viewing and searching (`cat`, `less`, `grep`)
- Safe command-line practices
- Hands-on exercises with solutions

---

### ⚙️ SLURM Basics
Learn how to submit, monitor, and manage jobs on the HPC cluster using **SLURM**.

- Job submission (`sbatch`, `srun`)
- Monitoring jobs (`squeue`, `sacct`)
- Resource requests (CPU, memory, time)
- Common errors and troubleshooting

---

### 🚀 Advanced Topics
Explore reproducible and scalable bioinformatics workflows.

- Workflow reproducibility
- Containers (Docker / Singularity)
- Visualization and result interpretation
- Best practices for production pipelines

---

## 🧠 Audience

This training hub is intended for:

- **New ProvLab staff**
- **Researchers** new to HPC environments
- **Bioinformatics beginners** seeking hands-on pipeline experience

No prior HPC or bioinformatics experience is required.  
Content progresses from **beginner** to **advanced**.

---

## ✅ How to Use This Repository

1. Start with **Linux Basics** if you are new to the command line
2. Complete **SLURM Basics** before running pipelines
3. Practice exercises before reviewing solutions
4. Apply skills to real ProvLab datasets

> 💡 Tip: Typing commands yourself (instead of copy-paste) helps build confidence and muscle memory.

---

## ⚠️ Safety Notes

- Always check your location with `pwd` before running commands
- Test wildcards with `ls` before using `rm`
- Use `-i` flags (`rm -i`, `mv -i`) when unsure
- Never run destructive commands outside designated practice directories
