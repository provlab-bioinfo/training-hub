# 🧬 ProvLab Bioinformatics Training Hub

Welcome to the **ProvLab Bioinformatics Training Hub**!  
This repository is the central resource for **hands-on bioinformatics training** at the **ProvLab (Calgary)**.  
It provides modular lessons, exercises, and examples to help new users gain practical computational biology skills.

## 📚 Training Modules

| Module | Description |
|--------|--------------|
| [01_linux_basics](modules/01_linux_basics/) | Learn essential Linux commands |
| [02_slurm_basics](modules/02_slurm_basics/) | Submit, monitor, and manage HPC jobs using SLURM |
| [03_file_management](modules/03_file_management/) | Manage data files on HPC systems |
| [04_bioinformatics_pipelines](modules/04_bioinformatics_pipelines/) | Run common pipelines (RNA-seq, variant calling, metagenomics) |
| [05_advanced_topics](modules/05_advanced_topics/) | Explore reproducibility, containers, and visualization |

## 🧠 Audience
- New staff, students, and trainees at ProvLab  
- Researchers seeking HPC and pipeline experience
