# Linux Basics for Bioinformatics Researchers

A comprehensive guide for biologists learning to use the command line on Red Hat Linux servers. This tutorial assumes no prior command line experience and focuses on practical skills needed for bioinformatics work.

## 🚀 Quick Start

New to Linux? Start here:
1. [Getting Started with PuTTY](docs/01-getting-started.md) - Connect to the server
2. [Quick Reference](QUICK-START.md) - Top 20 commands you'll use daily
3. [Command Cheatsheet](CHEATSHEET.md) - One-page reference guide

## 🎯 Learning Path

**Absolute Beginner** (Week 1)
- Complete tutorials 1-3
- Try exercises in `exercises/beginner/`
- Keep the cheatsheet handy

**Comfortable with Basics** (Week 2-3)
- Work through tutorials 4-8
- Practice with real data in `sample-data/`
- Try exercises in `exercises/intermediate/`

**Ready for Bioinformatics** (Week 4+)
- Study tutorials 9-12
- Apply skills to your research data
- Explore advanced exercises

## 💡 How to Use This Guide

1. **Read sequentially** if you're completely new to Linux
2. **Jump to specific topics** if you need particular skills
3. **Keep the cheatsheet open** while working
4. **Practice regularly** - use it or lose it!
5. **Don't memorize everything** - even experts look things up
